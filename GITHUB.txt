============================================================
  COMO COLOCAR O ATLAS NO GITHUB E ATUALIZAR EM OUTROS PC
============================================================


PASSO 1: CRIAR CONTA NO GITHUB
-------------------------------
1. Acesse: https://github.com
2. Crie uma conta gratuita.
3. Verifique seu email.


PASSO 2: CRIAR REPOSITORIO
-------------------------------
1. No GitHub, clique no "+" (canto superior direito).
2. Selecione "New repository".
3. Nome: Atlas-assistent
4. Selecione "Private" (privado).
5. Clique em "Create repository".


PASSO 3: ENVIAR O ATLAS PARA O GITHUB
----------------------------------------
Abra o terminal na pasta do Atlas:

  cd "C:\Users\krato\Desktop\OpenCode codigos\Jarvis"

Execute esses comandos (UMA VEZ SO):

  git init
  git add .
  git commit -m "Versao inicial do Atlas"
  git branch -M main
  git remote add origin https://github.com/SEU-usuario/Atlas-assistent.git
  git push -u origin main

(Substitua SEU-usuario pelo seu nome de usuario do GitHub)


PASSO 4: ATUALIZAR PELO GITHUB
--------------------------------
Sempre que fizer mudancas no Atlas, rode:

  git add .
  git commit -m "Descricao da mudanca"
  git push

No OUTRO PC, rode:

  git pull

Ou clique duas vezes em "Atlas-atualizar.bat".


PASSO 5: CLONAR EM OUTRO PC
------------------------------
No outro PC, instale o Git: https://git-scm.com/download/win

Depois rode no terminal:

  git clone https://github.com/SEU-usuario/Atlas-assistent.git
  cd Atlas-assistent
  "Instalar Atlas.bat"


============================================================
  RESUMO RAPIDO
============================================================

FAZER MUDANCAS:
  git add .
  git commit -m "minha mudanca"
  git push

ATUALIZAR OUTRO PC:
  git pull

OU: clique duas vezes em "Atlas-atualizar.bat"


============================================================
  COMANDOS UTEIS
============================================================

  git status           - Ver o que mudou
  git log --oneline    - Ver historico de mudancas
  git diff             - Ver mudancas detalhadas
  git pull             - Baixar atualizacoes
  git push             - Enviar atualizacoes


============================================================
  DICAS
============================================================

- Sempre committe mudancas com mensagens claras.
- Nao envie arquivos grandes (videos, etc).
- O venv/ e ignorado automaticamente (nao vai pro GitHub).
- lembretes.json tambem e ignorado (cada PC tem os seus).
- Use "Private" no repositorio para manter seguro.
